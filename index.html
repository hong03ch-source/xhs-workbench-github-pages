    数据与同步

    状态：仅本地保存
    数据存到你自己的 GitHub Gist（私密）：免费、不依赖电脑开机、多设备同步。 需要一个带 gist 权限的个人访问令牌。其它设备填同一个令牌会自动找到这份数据。
    令牌是账号级凭证，任何拿到它的人都能读写你的全部 Gist。 建议用 fine-grained token 且只勾 gist 权限；共用电脑上请选下面的「只记住本次会话」。
    高级：改用 Supabase
