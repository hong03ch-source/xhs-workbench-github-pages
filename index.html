    数据与同步

    状态：仅本地保存
    数据存到你自己的 GitHub Gist（私密）：免费、不依赖电脑开机、多设备同步。 需要一个带 gist 权限的个人访问令牌。其它设备填同一个令牌会自动找到这份数据。
    怎么拿令牌：GitHub → 头像 → Settings → 拉到最底 Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 权限只勾 gist 一个 → 生成后复制那串 ghp_ 开头的字（只显示一次）。
    注意必须选 classic，fine-grained 令牌目前不支持 Gist，填了会一直连不上。
    令牌是账号级凭证，拿到它的人能读写你的全部 Gist。所以权限只勾 gist、别勾多； 共用电脑上请把下面的「记住令牌」取消勾选。
    每台设备可以各生成一个令牌，互不影响，都指向同一份数据 —— 不用想办法把电脑上那个传到手机，在手机上现场生成一个新的更省事。
    高级：改用 Supabase
    多设备 不用在每台设备上重新申请令牌
    iPhone / iPad 注意：主屏幕上的图标和 Safari 是两套独立存储， 苹果不让它们互通，所以要各连一次。 建议装好图标后就只从图标进，别再用 Safari 开 —— 否则同一台设备上会存两份数据。
